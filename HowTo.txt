1) Åben Ubuntu
    - Skriv "wsl -d ubuntu-24.04

2) Naviger til projektmappen
    - cd .\BachelorProjectTamtam

3) Start mininet
    - sudo python3 Code/Topology.py --amount-of-clients X
        - x = antallet af ønskede klienter
    - vent på det står "mininet>"
    - tjek alle enheder er der med "nodes"

4) Start HTTP serveren
    - server python3 Code/Server.py &

5) Start PacketCapture
    - server .venv/bin/python -u Code/PacketCapture.py &

6) Generér normal trafik
    - client1 python3 Code/Client.py --requests 10 --interval 0.5 --client-id client1

7) Kontrollér resultaterne
    - sh ls -lh captured_packets.pcap

8) Tæl pakkerne
    - server .venv/bin/python -c "from scapy.all import rdpcap; print(len(rdpcap('captured_packets.pcap')))"

9) Kontrollér klientens CSV-fil
    - sh ls -lh logs/

10) Afslut forsøget
    - exit
    - Hvis problemer med genstart, skriv følgende i ubuntu terminalen
        - sudo mn -c
